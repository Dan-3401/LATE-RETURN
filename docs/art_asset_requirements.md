# 《迟归》 Art & Audio Asset Requirements

This document lists every visual/audio asset the demo uses, how it is currently
produced, and what a final hand-made replacement must satisfy so it can be
dropped in **without touching gameplay code**.

## Current status (honest summary)

| Area | Current source | Status |
|---|---|---|
| All pixel art (characters, environments, props, UI, icons, light textures) | Procedurally authored pixel art generated by `tools/art/*.py` (shared 150-colour palette, per-pixel shading, dithering, wear passes, selective outlines, then palette quantisation) | **In-game, shippable-quality for a demo, not placeholder rectangles.** Replacing with hand-animated sprites by a pixel artist would still improve character animation nuance (secondary motion, cloth, faces). |
| Character animation | Skeletal pose rig rasterised to pixels (`tools/art/character.py`), 48×48 frames | Functional and readable; the biggest candidate for a hand-drawn pass. |
| Font | Fusion Pixel 12px (OFL-1.1, `fonts/`) | Final. |
| Sound effects & ambience | Synthesised with numpy/scipy (`tools/audio/gen_audio.py`) | **Functional placeholders.** Recorded/designed foley is recommended for the final build (see Audio section). |

No `TEMP_PLACEHOLDER` ColorRect/Polygon2D art is used anywhere in the game.

Regenerate everything with:

```bash
python3 tools/art/gen_player.py && python3 tools/art/gen_zombie.py && \
python3 tools/art/gen_store.py && python3 tools/art/gen_street.py && \
python3 tools/art/gen_city.py && python3 tools/art/gen_camp.py && \
python3 tools/art/gen_ui.py && python3 tools/art/gen_fx.py && python3 tools/art/gen_lights.py && \
python3 tools/art/gen_foreground.py
python3 tools/audio/gen_audio.py
python3 tools/builders/build_store.py && python3 tools/builders/build_street.py && \
python3 tools/builders/build_camp.py && python3 tools/builders/build_actors.py
```

> The builders regenerate the scene files. If you hand-edit a map in the
> editor, stop running its builder (or port your edit into the builder).

## Global rules for replacement art

* Pixel density: **1 texel = 1 screen pixel** at the 480×270 base resolution (integer-scaled). Never scale sprites.
* Texture filter: **Nearest** (project default). No mipmaps.
* Tile grid: **16×16**.
* Characters: **48×48 frames**, feet on the bottom row, centred horizontally (pivot = bottom-centre). Visible body ≈ 20×44 px.
* Transparent PNG, no semi-transparent edges (1-bit alpha), palette consistent with `tools/art/pixlib.py:RAMPS`.
* Facing right in the source; the engine mirrors for left.

## Audio (replace with recorded foley for final)

All files live in `audio/sfx`, `audio/amb`, `audio/ui` and are looked up by name
(`name.wav` or `name_1.wav … name_8.wav` for random variations) by
`AudioManager`. Replacing a file with the same name needs no code change.

|---|---|
| Player | `step_1-4`, `step_soft_1-3`, `step_run_1-4`, `jump`, `land_1-2`, `breath_in`, `breath_out`, `gasp_1-3`, `wake_breath`, `player_hurt_1-2`, `player_death`, `cough`, `heartbeat` |
